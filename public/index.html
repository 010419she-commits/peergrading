本地 Agent 生成初稿

从同一项任务开始，由本地模型产出第一版文字或代码成果，交给云端 Agent 审查。

流程演示，不会调用模型或上传内容。

设置轮次上限，随时停止，最终成果由你审阅。使用云模型时，相关内容会发送到你选择的服务。

简单的界面，认真做事

把注意力留给值得做的事。

01

像聊天一样开始

任务输入放在底部，协作过程居中展开。历史、模型配置与成果按需打开，日间和夜间一键切换并记住选择。

02

接着你的工程往下做

通过 Kimi Code、Codex 或 Claude Code CLI，在独立 Git worktree 中编辑真实文件，保留差异、提交与验证记录，由你审阅后合并。

worktree 隔离文件与分支；验证命令仍以本机用户权限运行。

03

少一点重复等待

完整快照支持并行预审，采纳前核对 SHA-256。精确缓存只复用全部有效输入完全一致的结果，不跳过审查和验证。

加速来自任务调度与应用层缓存，不承诺 token / KV 级共享计算。

如何接入自己的 Agent？

本地模型：先启动 Ollama 或 LM Studio 并加载模型，桌面软件可自动识别本机兼容服务。

仓库编辑：需要 Git 和已安装、登录的 Kimi Code、Codex 或 Claude Code CLI。

云端 API：使用自己的 OpenAI 兼容服务配置。CLI 登录、订阅和 API 费用由对应供应商管理。
