隐私政策

更新及生效日期：2026 年 10 月 16 日

本政策适用于 peergrading.ai 网站及 PeerGrading 桌面软件。运营者及个人信息处理者为王国珺（下称“我们”），联系邮箱为 010419She@gmail.com。

请先了解数据去向。仓库协作在您的电脑上运行，PeerGrading 账号服务器不因您选择本机仓库而自动接收整份仓库。所选云端 Agent 仍可能将任务、代码片段、差异和工具结果发送给其模型服务商；“本机运行 CLI”不代表模型在本机推理。账号服务器目前部署在美国洛杉矶地区。
信息与用途代码与 AI第三方与跨境保存与安全您的权利

一、处理哪些信息，为什么处理

账号与身份验证
邮箱登录会处理您的邮箱、验证码校验记录及必要的防滥用信息，验证码以校验值保存。Google 或 GitHub 登录会返回账号标识及授权范围内的昵称、头像等基本资料，用于创建、识别或关联 PeerGrading 账号。Google 登录申请基本身份、邮箱和资料范围；当前 GitHub 登录只申请基本用户资料权限，不申请仓库权限，也不持久保存 GitHub 访问令牌。可用渠道以页面为准；历史微信账号关联记录可能为维护既有账号而保留。
设备、使用权与交易
我们处理用户 ID、设备名称、设备授权、登录及最近连接时间、试用和会员状态、协作次数、订单号、方案、金额、币种、付款状态、交易标识及邀请关系，用于登录、使用权核验、履行订单、奖励、防欺诈和售后。设备名称可能包含电脑主机名，您可在系统设置中调整。完整银行卡号和安全码由支付机构的托管收银台处理，PeerGrading 不要求您通过邮件或聊天提供这些信息。
任务及协作记录
桌面模式的任务、Agent 对话、代码差异、检查输出、版本、补丁、媒体和报告保存在本机应用数据目录或任务 worktree。账号服务器通过使用权接口核验权益与次数，不通过该接口上传任务正文或本机仓库。如您使用另行启用的网页版工作台、主动上传资料或提交故障日志，相应内容会在该服务器或支持渠道处理。
本机配置及剪贴板
软件识别已安装的 Agent 和必要的登录状态，调用您配置的 CLI 或接口。使用剪贴板中转时，软件会在该协作过程中读写剪贴板并切换指定应用。接口直连及媒体生成使用您主动配置的 API Key；桌面模式的相应配置保存在本机，云端模式的相应配置保存在运行该服务的服务器。不要将密钥粘贴到任务正文。
网络、安全与偏好
必要的访问与安全记录可能包含 IP 地址、请求时间和路径、响应状态、浏览器及系统信息。验证码接口使用经处理的邮箱、IP 等限流标识。必要 Cookie 用于浏览器识别、登录及安全校验，本地存储用于语言偏好；邀请链接可能用 Cookie 暂存邀请码。当前服务页面没有部署广告定向跟踪。

我们依具体场景，为订立和履行服务合同、履行法定义务，或在取得所需同意后处理信息；安全措施限于必要范围。拒绝提供登录或交易所必需的信息可能使对应功能无法使用，但不影响浏览公开介绍及政策。可选媒体生成与剪贴板中转仅在您使用相应功能时处理相关内容。

二、代码、AI 服务与您的选择

选择 Kimi Code、Codex、Claude Code 或其他云端 Agent 后，本机 CLI 或所选接口会将任务及所需上下文发送给对应服务商。服务商可能处理提示词、代码、文件、工具结果、使用量与输出；其保存期限、训练使用方式和退出选项受其政策、账号方案及您的设置约束。我们不能承诺第三方不保存数据或不用于训练。

LM Studio、Ollama 等服务的数据去向取决于模型和接口地址；接口或工具若连接外部服务，数据仍可能离开本机。运行前请核对所选 Agent、接口、权限和提供代码的授权，避免提交密钥、无关个人信息或无权提供的保密资料。

仓库协作在独立任务分支及 worktree 中修改文件并执行配置的检查，不自动合并或推送到远程仓库。Agent 工具和检查命令可能访问网络。删除 PeerGrading 记录不会自动删除第三方已保存的内容或原始仓库文件。

三、第三方服务与跨境处理

以下服务仅在相关功能被实际使用时处理所需信息：

  • 登录与邮件：Google、GitHub 提供您选择的登录；验证码由实际配置的 SMTP 邮件服务或 Resend 发送，处理收件地址和验证码邮件。头像可能从授权平台的外部地址加载。
  • AI 与媒体：Moonshot / Kimi、OpenAI、Anthropic 或您配置的其他服务处理任务上下文和生成请求；媒体功能需另行启用。
  • 支付：开通后由微信支付、Airwallex 等机构处理相关订单、交易及支付核验信息；支付机构另行收集的付款信息以收银台说明为准。
  • 托管与网络资源：账号服务器及基础设施服务商处理网站、账号功能所需的数据。官网或工作台加载的 Google Fonts 字体、Cloudflare cdnjs 资源会向对应服务提供必要网络请求信息。本政策与条款页面仅加载本站样式。

账号、设备及订单的云端数据目前在美国洛杉矶地区处理和保存；登录、邮件、支付或 AI 服务可能在其他国家或地区处理数据。您可通过本页邮箱询问相关处理活动和行使权利。跨境提供、敏感信息等场景依法需要的额外告知、单独同意及其他程序，应另行履行；本政策不替代法定单独同意。

我们不出售您的个人信息。仅为实现所选功能、取得您授权、依法履行义务、应对安全事件或处理争议所必需时向相应接收方提供信息。第三方独立服务适用其自身政策。

四、保存期限与安全

账号、设备、会员及订单数据在提供服务、处理售后与履行法定义务所必要的期间保存；不再需要且没有法定保留理由时删除或匿名化。交易及争议记录按适用法定期限处理，不因退出登录立即删除。

当前登录会话通常有效 30 天，验证码和设备连接码通常有效 10 分钟，浏览器识别 Cookie 最长约 1 年，邀请 Cookie 通常为 30 天。“失效”不等于数据库记录同时物理删除，过期认证事务由清理流程移除。您可在浏览器清除 Cookie；禁用必要 Cookie 可能影响登录和验证。

本机协作记录、媒体及任务 worktree 当前没有统一的自动到期清理机制，请按需备份或删除。退出或卸载软件不保证清除应用数据目录及 worktree。服务器协作记录如存在，可申请删除。备份随替换或清理处理；依法应保留或技术上暂不能立即删除的数据，限制为必要保存与安全用途。

我们采用 HTTPS、访问控制、会话及设备令牌校验、防跨站请求伪造校验、必要权限和本机凭证文件权限等措施。没有系统能保证绝对安全，请保护电脑、账号、CLI 登录及私人备份。发生依法需要通知的信息安全事件时，我们会依法补救及通知。
