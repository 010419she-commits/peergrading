PRIVACY / DATA

Privacy Notes

Updated and effective: October 18, 2026

These notes apply to the PeerGrading open-source desktop app and the peergrading.ai download site. PeerGrading does not provide accounts, memberships, orders or payments, and does not ask you to create an account.

Local-first does not mean every byte stays on your computer. Tasks, sessions and model settings are stored locally by default. Content is sent to a provider only when you choose a cloud agent or cloud model.

1. Local data and your control

The desktop app stores tasks, agent conversations, versions, patches, check output, media, run reports and your selected model connections on your computer. API keys are used only to call the configured model providers, are saved in the local data directory, and are not included in public sessions, installers or the GitHub source repository.

Repository collaboration creates a separate task branch and Git worktree from the repository you select. The app does not upload the whole repository to the download site merely because you selected it, and it does not automatically merge or push the original repository.

When clipboard relay is used, the app reads and writes the clipboard and activates the target app you selected during that collaboration. Language preferences use local browser or app storage and do not require account cookies.

2. Third-party agents and model providers

Kimi Code, Codex, Claude Code, Kimi, OpenAI, Anthropic and any other providers you configure process prompts, code, diffs, tool results, usage and output under their own rules. A CLI running on your computer does not necessarily mean the model itself runs locally.

The data path of Ollama, LM Studio, NInfer, Strata or another OpenAI-compatible endpoint depends on its actual address. If the endpoint is on a LAN or the public internet, content may leave your computer. Third-party retention, training use, pricing and opt-out options are governed by each provider and by your own settings.

Submit only code and content you are authorized to use. Do not place passwords, API keys, private keys, unrelated personal information or confidential material in task text, logs, screenshots or GitHub issues.

3. Public download site

The download site provides only project information, open-source links, privacy and terms pages, and a GitHub Releases installer manifest. It does not provide a collaboration workspace, server-side repository operations, accounts, payments or legacy compatibility APIs.

The site does not load Google Fonts, third-party JavaScript CDNs, advertising or behavioral analytics. Visiting GitHub source, issues or Releases is processed by GitHub under its own privacy policy.

Hosting and reverse-proxy infrastructure may process IP addresses, request times, paths, response status and browser information for security, troubleshooting and abuse prevention. The site does not use an account system to connect those technical logs to a specific user.

4. Retention and deletion

Local collaboration records, media, model settings and task worktrees have no single automatic expiry. You choose when to back them up or delete them. Quitting or uninstalling the app does not guarantee that those directories are removed.

Public technical logs are retained by the hosting environment only as needed for security and operations. PeerGrading does not store account databases, device tokens, memberships, orders or payment records, so there is no corresponding cloud account deletion workflow.

We use loopback binding, Host / Origin / CSRF checks, configuration redaction and pre-release secret scanning. No system can guarantee absolute security; protect your computer, CLI sign-ins, API keys and private backups as well.

5. Issues and policy updates

To report an implementation issue or discuss local-data behavior, open a GitHub issue. Before posting publicly, remove keys, private code, account information and unnecessary personal data.

Material changes to these notes will update the date and be shown on this page. Previous versions can be reviewed through the public repository history.
