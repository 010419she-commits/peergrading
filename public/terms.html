服务条款

更新及生效日期：2026 年 10 月 17 日

本条款适用于 PeerGrading 开源桌面软件和 peergrading.ai 下载站。核心软件以 MIT 许可证提供，不需要 PeerGrading 账号、会员或付款。第三方 Agent 和模型服务仍受其自身条款约束。

请重点阅读：自动审查和测试不能保证输出无误；云端辅助只减少任务等待，不改变审查或通过条件。您应审阅代码、差异、依赖和检查结果后再决定运行、合并或部署。
开源许可协作与使用第三方服务责任与争议更新与联系

一、开源许可与服务范围

PeerGrading 用于编排两个 Agent 轮流完成、审查、讨论和修改任务，并可保存版本、补丁和检查结果。源代码按 MIT 许可证 提供；您可以在该许可证范围内使用、复制、修改和分发。

下载站仅提供项目介绍和 GitHub Releases 下载入口。旧账号、设备配对、会员、订单和支付接口不再构成当前服务的一部分。

二、仓库协作与使用边界

您授权软件在所选目录和任务范围内读取必要文件、创建独立任务分支及 worktree、调用 Agent 修改文件，并执行您填写的检查命令。默认保留任务结果供您审阅，不自动合并或推送原始仓库。

运行前请备份重要内容并确认仓库、命令、Agent 和执行环境。检查命令可能执行项目代码、安装依赖或访问网络；Git worktree 不是操作系统安全沙箱，本机执行也不天然与电脑隔离。

“审查通过”只表示该次流程满足已配置的审查和检查条件，不保证成果安全、正确、适销或适合特定用途。未运行、失败、达到轮数上限或取消的任务不能当作已验收成果。

不得利用软件实施违法行为、侵犯隐私或知识产权、传播恶意软件、未授权访问或绕过第三方权限。您应仅提交有权使用的代码、命令和内容。

三、第三方 Agent、模型与费用

Kimi Code、Codex、Claude Code、模型接口和媒体服务由第三方提供。您需自行完成安装、授权并遵守其条款；可用性、额度、费用、数据处理和输出限制由对应平台决定。PeerGrading 不销售第三方订阅或 API 用量。

选择云端 Agent 或接口即表示您允许本机软件把任务所需上下文发送给对应服务商。第三方内容的保存、训练和退款事宜需要直接向该服务商处理，卸载 PeerGrading 不会自动取消第三方订阅。

您保留输入代码和任务内容原有的权利。AI 输出的权利与可分发性取决于适用法律、第三方约定和已有材料；请在使用前自行审查。

四、责任与适用法律

软件和网站按“现状”提供，MIT 许可证中的保证与责任条款适用于开源代码。我们不承诺第三方永不中断、AI 输出无误或检查覆盖全部问题，也不排除依法不能排除的责任。

用户选择的命令、无权提供的内容、未经审查的部署以及第三方独立行为造成的影响，按事实、因果关系、适用法律和相应许可条款确定责任。

服务关系及争议依法确定适用法律；用户通常居住地的强制性消费者保护规则不被排除。请先通过 GitHub issue 沟通一般实现问题。

五、更新与联系

功能、文档和本条款可能随版本更新，更新会注明日期并可通过公开仓库核对。重大变化不以旧账号或订单规则推定，因为当前版本不提供这些系统。

问题反馈请使用 GitHub issue。请不要在公开反馈中提交密码、API Key、私钥或不必要的个人信息。隐私边界见隐私说明。
