# 0.4 桌面登录、会员与下载官网

PeerGrading 的主要入口是 macOS / Windows 软件。现有仓库协作、账号、会员、订单、邀请和设备管理在软件里完成；[peergrading.ai](https://peergrading.ai) 首页介绍产品并提供下载，不要求先登录或购买。

官网继续承载第三方授权确认、支付服务跳转与敏感身份验证。把账号界面放进软件，并不把 Google / 微信的授权表单嵌入 Electron，也不把商户密钥打包给用户。

## 日常使用

1. 下载并打开软件。未登录时显示「登录 / 注册」，不会先要求手填 8 位码。
2. 点「登录 / 注册」，软件通过系统默认浏览器打开授权页，连接码已自动填写。
3. 在浏览器使用当前已开放的 Google / 微信方式登录；已有浏览器会话时，核对当前账号与设备后确认连接。第一次授权会创建账号。
4. 确认后浏览器返回本机回调页，软件自动连接并进入工作台。浏览器页可以关闭；若操作系统没有切换窗口，手动回到 PeerGrading 即可。
5. 从工作台打开「账号与会员」，在软件窗口内查看会员状态、方案、订单、邀请奖励、已关联身份及设备。点「返回工作台」继续协作。

仓库模式需要本机已有 Git，以及已安装、已登录的 Claude Code / Codex CLI。选择工作区干净且有提交的仓库，任务在独立分支与 worktree 中运行；查看差异、检查结果和提交后自行合并。详细限制与使用方式见 [仓库协作说明](repository-collaboration.md)。

## 8 位配对码是什么

这是把**这一次软件登录请求**与浏览器里的账号关联起来的连接码。它由 8 个随机字母数字组成，通常显示成 `ABCD-EFGH`，中间的连字符只是为了阅读方便。

| 代码 | 用途 | 有效期 |
|---|---|---|
| 登录连接码（旧称配对码） | 授权当前电脑连接 PeerGrading 账号 | 10 分钟；成功兑换一次后失效 |
| 邀请码 | 在软件内领取好友邀请奖励 | 按服务端邀请规则与注册领取窗口判断 |
| 设备令牌 | 软件后端向服务端证明设备已经获得授权 | 保存于本机后端，可退出或从设备列表撤销 |

连接码不是密码、会员激活码或邀请码。知道连接码也不能直接读取现有账号：浏览器仍需登录并明确确认授权，软件用另一份私密请求码兑换设备令牌。

新版把 8 位连接码放在登录页「连接码与手动连接（备用）」里，默认无需输入。只有授权页没有自动填写、或者使用旧版软件时，才在浏览器确认页手动填写。只确认自己刚在软件中发起的请求；不要把连接码转发给别人。

遇到「已过期」「已使用」「已取消」时，回软件重新点登录，使用新生成的请求。旧页与旧码不能重复授权。没有打开浏览器时可点「重新打开授权页」；点「取消」会结束本次本机等待。

## 会员、订单与付款

「账号与会员」显示账号 ID、会员 / 试用状态、方案、订单、邀请奖励，以及当前电脑和其他已连接设备。软件用云端最新结果刷新这些信息，不在本机自行决定付款成功或永久会员。

- **免费内测默认开启**：登录用户免费使用，购买按钮标记内测结束后开放；服务端拒绝创建收费订单。官网没有购买入口。
- **内测结束后**：软件按云端公开方案显示试用、早鸟终身版或月付。价格、名额和权益以服务端配置为准；现有月付到期不会自动扣费。
- **微信 Native 支付**：渠道开通后，从软件创建订单并显示本订单二维码，用微信扫码；软件轮询并可主动查询付款结果。
- **海外 Visa / Mastercard**：Airwallex 全球收单获批并配置后，从软件发起订单，在系统浏览器打开托管结账；付款后回软件点击「查询支付结果」或刷新。软件不收集完整银行卡信息。
- **付款结果**：只有服务端验证的通知或渠道主动查询结果能开通会员。浏览器回到成功页、手动输入订单号或关闭窗口都不会直接授予权益。

同一订单选择付款渠道后会锁定该渠道。重新打开订单应继续原渠道；如需换渠道，先按服务端规则处理原订单，避免重复付款。

软件显示哪些登录、方案和收款按钮，取决于生产端实际配置。**微信登录、微信支付与 Airwallex 海外信用卡收款分别需要申请、审核和凭证；当前微信及支付仍待配置开通。**本地模拟与测试订单只能验证实现，不表示商户已经获准收款。配置说明见 [微信登录接入](wechat-login-setup.md) 与 [收款接入](payments-setup.md)。

## 身份验证与设备

设备令牌允许软件查询账号、下单、查询订单、领取邀请和管理设备，不会被转换成浏览器登录 Cookie。

「登录与设备」可显示已关联登录身份，并提供管理入口。绑定 / 解绑、切换登录身份、重新验证等敏感操作仍在系统浏览器进行；浏览器需要自己的登录会话，绑定与解绑还要求近期身份验证。仅持有设备令牌不能绕过这些要求，也不会自动接管浏览器中的其他账号。

退出软件账号会清除本机设备授权并尝试撤销云端令牌；设备列表也可断开指定电脑。重新连接需要重新登录。第三方 Agent 的登录与 PeerGrading 账号独立，退出 PeerGrading 不代替 Claude Code / Codex 自身的退出操作。

## 本机、官网与接口的边界

| 位置 | 职责 |
|---|---|
| 软件本机 `http://127.0.0.1:<随机端口>/account` | 登录界面、会员方案、订单、邀请和设备 UI |
| 软件本机 `/app` | 仓库选择、本机 Agent、协作时间线、差异、检查与版本 |
| 官网 `/` 与 `/api/download/latest` | 产品说明、最新 macOS / Windows 下载信息；首页不请求登录状态 |
| 官网 `/login`、`/auth/*`、`/device` | 系统浏览器中的 Google / 微信授权与电脑连接确认 |
| 官网 `/account#security` | 敏感身份验证与旧版浏览器账号兼容入口 |
| 本机 `/api/local/auth/*` | 发起、轮询、接收本次登录回调与退出 |
| 本机 `/api/local/account/*` | 有限白名单内的账号、订单、邀请、设备代理接口 |
| 官网 `/api/desktop/account/*` | 设备令牌鉴权的账号服务；与浏览器 Cookie 鉴权分开 |
| 官网 `/desktop/checkout/:ticket` | 系统浏览器信用卡托管付款启动页，短时一次性票据，不是登录会话 |

Google / 微信控制台填写的仍是官网公开回调地址，例如 Google 为 `https://peergrading.ai/auth/google/callback`。本机 `127.0.0.1` 回调是软件连接确认后返回电脑的地址，不应替换第三方控制台里的公开回调地址。

授权返回地址限制为本机 `127.0.0.1` 的随机非特权端口与固定路径，结合本次随机状态校验。设备令牌由本机后端保存到应用数据目录的 `data/device.json`，文件权限设为 `0600`；云端只存令牌散列，前端与回调 URL 不接收长期令牌。该本机数据文件应当作为私人凭证保护。

## 开发与配置

Node.js 需要 24 或更新版本。验证本地云端与桌面连接时，分两个终端运行：

```bash
# 终端一：云端接口的本地开发服务，提供仅开发环境可用的测试身份
PORT=3001 BASE_URL=http://localhost:3001 npm run dev
```

```bash
# 终端二：先构建，再启动连接本地云端的桌面软件
npm run desktop:local-cloud
```

连接正式服务使用 `npm run desktop`，默认 `CLOUD_URL=https://peergrading.ai`。登录页「高级：服务地址」供开发者连接自己的账号服务；留空恢复默认地址。已登录时先退出，才能修改服务地址，避免把旧设备授权带到其他服务。

生产服务仍需配置自己的 `SESSION_SECRET`、Google / 微信 OAuth 凭证，以及希望开放的支付商户信息；第三方授权与回调域名需匹配生产域名。未配置的渠道不展示，`DEV_LOGIN` 在生产环境无效。保持免费内测，直到真实商户联调与付款核验完成。真实密钥仅存在服务器私人配置中，不能提交到 GitHub 或放进安装包。

## 常见情况

| 现象 | 处理 |
|---|---|
| 软件显示等待浏览器授权 | 在系统浏览器完成登录并确认当前电脑；可在软件重新打开授权页 |
| 连接码已过期或已使用 | 回软件重新发起登录，不能重复使用旧页或旧码 |
| 授权完成但未切回软件 | 手动回到软件，保持软件运行；软件也会轮询结果 |
| 登录方式为空 | 服务端尚未配置可用渠道；配置后重新打开授权页，不用反复输入连接码 |
| 找不到微信或信用卡支付按钮 | 可能仍处免费内测，或对应商户渠道未开通；查看软件中的状态与服务端配置 |
| 银行卡付款完成但仍待付款 | 回软件点击「查询支付结果」，等待服务端从渠道核验；不要立即再付一次 |
| 账号服务暂不可用 | 检查网络与服务地址；已登录用户最多沿用最近 72 小时内的会员 / 试用缓存，新登录、下单和支付核验需要联网 |
| 设备已断开或账号登录失效 | 在软件重新登录；断开的旧设备令牌不能再次授权 |

公网生产站点默认不开放服务器仓库路径操作。官网下载页面不会扫描访客电脑；本机 Agent 识别与文件修改由安装后的软件完成。Agent 向其模型服务发送哪些代码内容，仍取决于所选 Agent 与用户配置。
